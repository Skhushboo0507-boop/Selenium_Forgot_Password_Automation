# Selenium Forgot Password Automation

## Project Overview

This project automates the "Forgot Password" workflow of a web application using Selenium WebDriver and Python. The automation script validates user interactions, password reset functionality, and form submission behavior through end-to-end UI testing.

## Key Features

✔ Automated Forgot Password workflow

✔ Email field validation

✔ Password and Confirm Password handling

✔ Form submission automation

✔ XPath and CSS Selector implementation

✔ End-to-End UI Testing

## Technologies Used

- Python
- Selenium WebDriver
- Chrome Browser
- PyCharm

## Test Scenario

1. Launch the application.
2. Navigate to the Forgot Password page.
3. Enter a valid email address.
4. Enter a new password.
5. Confirm the password.
6. Submit the form.
7. Verify successful execution of the password reset workflow.

## Selenium Concepts Covered

- WebDriver Initialization
- Locators (XPath, CSS Selector, Link Text)
- Form Handling
- Element Interaction
- Test Automation
- UI Validation
